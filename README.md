# AI-Powered-Resume-Analyzer-Career-Assistant
Developed a full-stack **AI-powered Resume Analyzer & Career Assistant** using the **MERN stack** and **Gemini API** to analyze resumes, extract technical skills, identify skill gaps, and generate personalized career improvement recommendations. Implemented secure **JWT-based authentication**, RESTful APIs, and MongoDB-based data management for handling user profiles, resume data, and AI-generated insights. Designed an interactive React.js interface with seamless frontend-backend integration to deliver an efficient and user-friendly resume evaluation experience. Integrated AI-driven analysis workflows to provide actionable suggestions aligned with job requirements and career goals.
