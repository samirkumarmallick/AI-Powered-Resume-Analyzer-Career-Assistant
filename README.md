# AI-Powered Resume Analyzer & Career Assistant

## Project Overview

Developed a full-stack **AI-powered Resume Analyzer & Career Assistant** using the **MERN stack** and **Google Gemini API** to help users evaluate their resumes and receive personalized, actionable career guidance.

## Key Features

* **AI-Powered Resume Analysis:** Analyzes resume content and provides structured insights on strengths, weaknesses, and areas for improvement.
* **Technical Skill Extraction:** Automatically identifies and categorizes technical skills from uploaded resumes.
* **Skill Gap Analysis:** Compares existing skills with target job requirements to highlight missing or recommended skills.
* **Career Recommendations:** Generates personalized improvement suggestions based on the user's resume, skills, and career goals.
* **Secure Authentication:** Implemented **JWT-based authentication** with protected routes and user-specific data access.
* **Resume & User Data Management:** Utilized **MongoDB** for persistent storage of user profiles, resume information, and AI-generated analysis.
* **RESTful Backend APIs:** Designed and integrated scalable REST APIs for authentication, resume processing, analysis, and user data management.
* **Interactive Frontend:** Built a responsive **React.js** interface with seamless communication between frontend and backend services.
* **AI Integration:** Integrated the **Gemini API** into the analysis workflow to generate contextual and actionable career insights.

## Technology Stack

**Frontend:** React.js, JavaScript, HTML, CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB

**Authentication:** JWT, Cookies

**AI:** Google Gemini API

**Architecture:** RESTful APIs, MERN Stack
