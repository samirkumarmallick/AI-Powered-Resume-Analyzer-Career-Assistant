# AI-Powered-Resume-Analyzer-Career-Assistant
An AI-driven full-stack application built using the MERN stack and Google Gemini API that analyzes resumes, identifies skill gaps, and provides personalized career improvement recommendations. The platform helps users optimize their resumes by leveraging AI-powered insights based on technical skills, experience, and targeted job requirements.

Key Features
AI-Powered Resume Analysis: Uses the Gemini API to analyze resume content, extract key skills, identify improvement areas, and generate personalized recommendations.
Skill Gap Detection: Evaluates existing skills against career goals and highlights missing technical competencies to improve employability.
Secure Authentication: Implemented JWT-based authentication and authorization for secure user access and protected application resources.
RESTful Backend APIs: Designed and developed scalable REST APIs using Node.js and Express.js for seamless client-server communication.
Data Management: Integrated MongoDB for efficient storage and retrieval of user profiles, uploaded resumes, and AI-generated analysis reports.
Responsive User Interface: Built an interactive React.js frontend for a smooth and user-friendly experience.
Tech Stack

Frontend: React.js, JavaScript, HTML, CSS
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT
AI Integration: Google Gemini API
